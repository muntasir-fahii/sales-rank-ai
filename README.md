# AI Sales Coach – Web Application Landing Page

Welcome to **AI Sales Coach**, an AI-powered web application that helps users improve their sales skills and learn AI concepts through an interactive chatbot and curated course content.

## 🧠 Features

- 🤖 **AI Chatbot**: Users can interact with a live AI coach for real-time suggestions, templates, and sales coaching tips.
- 📚 **AI Learning Modules**: Access structured courses to learn AI fundamentals, use-cases, and best practices.
- 💬 **Suggestion Coaching**: Easily engage with pre-built question prompts for instant feedback.
- 🎨 **Responsive UI**: Built with modern design using **ReactJS** and **Tailwind CSS**.
- 💡 **Real-Time Analysis**: View AI confidence levels and coaching insights.
- ⚡ **Quick Actions**: Generate scripts and practice pitches directly from the UI.

## 🛠️ Tech Stack

- **ReactJS** – Component-based UI
- **Tailwind CSS** – Utility-first styling
- **React Icons** – Icon library
- **Custom Components** – ChatBox, Navbar, Hero, Courses, Faqs, Testimonials, Footer, and more
